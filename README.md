# Rose Turtle Art

Trëndafil i vizatuar me Python turtle — petale të kuqe, kërcell dhe gjethe të gjelbra. Demoja web ekzekuton në browser të njëjtën sekuencë komandash turtle si origjinali (circle/fd/lt/rt/setheading me mbushje), e animuar progresivisht.

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

- `TREE`

## 🖥️ Si ekzekutohet origjinali
Kërkon Python 3:

```
python Draw_Rose_Python.txt
```
(ose riemërtoje në `.py`)
